# 🇯🇵 Japan Travel Guide & Recommendations

An interactive, responsive web application designed to help users discover Japan. The site features an interactive map and dedicated city pages equipped with dynamic image carousels and travel recommendations. 

## 📍 Featured Cities
The interactive map allows users to explore points of interest, photography and recommendations for seven major locations:
* **Tokyo:** The bustling capital, featuring the Tokyo Tower, Akihabara and Shibuya.
* **Kyoto:** The cultural heart, featuring Fushimi Inari, the Golden Pavilion and traditional shrines.
* **Osaka:** Featuring the iconic Osaka Castle and Universal Studios.
* **Kobe:** Highlighting the cityscape and telepherique.
* **Nara:** Famous for its historic temples and free-roaming deer.
* **Uji:** The matcha capital, featuring the Byodo-in Temple.
* **Takahama:** Highlighting coastal beauty, Wakasa Wada Beach and rice paddies.

## 🛠️ Tech Stack
This project was built entirely without external libraries to solidify fundamental web development skills:
* **HTML5:** Semantic structuring and responsive meta-tags.
* **CSS3:** Custom styling, layout management, and responsive design targeting mobile and desktop.
* **Vanilla JavaScript:** DOM manipulation for the interactive map and dynamic image carousels.
* **Fonts:** Google Fonts (Shippori Mincho, DM Sans).

## 🌐 How to Run Locally
Since this is a static website, no build steps or servers are required.
1. Clone the repository to your local machine.
2. Open `pagesHTML/pagedegardebis.html` in any modern web browser (Chrome is preferred).
